## 🔧 Troubleshooting Installation

### "App not installed" Error

```bash
# Solution 1: Clear cache
adb shell pm clear org.aimovie

# Solution 2: Uninstall and reinstall
adb uninstall org.aimovie
adb install aimovie-1.0.0.apk

# Solution 3: Install with downgrade
adb install -r -d aimovie-1.0.0.apk
```

### "Insufficient Storage" Error

- Free up at least 500MB on your device
- Move files to SD card if available
- Use storage cleaner app

### "Unknown Sources" Warning

On Android device:
1. Go to Settings
2. Security
3. Enable "Unknown Sources"
4. Try installing again

### App Crashes on Launch

```bash
# Clear app data
adb shell pm clear org.aimovie

# Uninstall and reinstall
adb uninstall org.aimovie
adb install aimovie-1.0.0.apk
```
